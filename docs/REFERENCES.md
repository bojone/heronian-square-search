# 参考资料

以下是本项目启动时使用的公开资料。它们用于了解问题背景、已知结果和椭圆曲线构造；最终计算结论以本仓库的源码、状态记录和独立整数验证为依据。

1. **平方边长海伦三角形讨论（第一页）**  
   <https://bbs.emath.ac.cn/thread-49962-1-1.html>  
   用户提供的数学论坛讨论，包含问题背景与已知解的交流。

2. **同一论坛讨论（第二页）**  
   <https://bbs.emath.ac.cn/thread-49962-2-1.html>  
   延续前一页的讨论。论坛可能拒绝自动访问或要求登录，因此这里保留原始网址供人工查阅，不把网页内容作为可机器复核的证据。

3. **The Arithmetic Geometry of Square-Sided Heron Triangles**  
   <https://arxiv.org/abs/2605.22458>  
   arXiv:2605.22458 [math.NT]，DOI：<https://doi.org/10.48550/arXiv.2605.22458>。论文研究带有两个标记平方边的有理海伦三角形、相应椭圆曲线和 K3 曲面，以及第三个边也为平方数时所得到的曲线。摘要还说明两个椭圆纤维构造之间的关系。该文是 `experiments/elliptic/` 探索的理论背景；本项目的穷举覆盖不依赖该文中的猜想。

4. **OEIS A318575**  
   <https://oeis.org/A318575>  
   该序列列出两组已知解的面积：第一组对应边长 `(1853^2, 4380^2, 4427^2)`，第二组对应边长 `(11789^2, 68104^2, 68595^2)`。本仓库的 `scripts/verify.py` 直接从根边重新计算面积，而非从序列读取面积。

## 引用与结论边界

- 网页是背景和已知解的来源，不代替本项目的覆盖审计。
- 论文中关于两边平方的参数化不能直接推出第三边平方解的有限枚举范围。
- 双纤维实验的系数界不是根边枚举界，不能用它替代正式的一千万根边搜索。
- 本项目报告的结论仅为：在根边 `1..10000000` 的完整已审计范围内，没有找到两组已知解之外的本原解。
